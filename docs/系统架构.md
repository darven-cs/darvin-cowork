# 项目描述
这是一个工作桌面agent,适用于日常工作,包括创作,数据分析,ppt制作,视频制作,日常文件处理等问题,是个人的贴心助手,配置个人工作流使用

# 技术选型
electron作为桌面开发,golang作为agent runtime去跑(electron子进程),Vue3是前端页面编写,Tailwind CSS v4 是前端样式方案(@tailwindcss/vite 接入),AI 产物预览走自建 sandboxed iframe 渲染器 (Artifact 渲染器)

## 前端
- **目标栈**: Vue3 + Tailwind CSS v4 + Artifact 渲染器
  - **Vue3**: 视图层框架,函数组件 + `<script setup>` 风格
  - **Tailwind CSS v4**: 通过 `@tailwindcss/vite` 插件接入;`index.css` 顶部 `@import "tailwindcss";`;样式优先 utility class,跨组件复用的设计 token 走 `@theme` 块
  - **Artifact 渲染器**: 位于 `src/renderer/services/artifact-renderer/`,sandboxed iframe 隔离渲染 AI 生成的 HTML / SVG / Mermaid / React 组件 / 代码块等产物,对外只暴露受控 API (`mount` / `update` / `destroy`)
- **当前状态**: Vanilla TS + HTML (Hello World 占位),按上述目标栈迁移中

## 后端
golang + sqlite

## 主进程数据管理
- **SQLite 存储**: 用户设置、对话历史、上下文缓存
- **IPC 通信**: 与 Go Agent、子进程管理、数据读写

## 渲染进程职责
- **前端 UI**: Vue3 组件渲染,Tailwind CSS v4 utility class 样式
- **状态管理**: Pinia 运行时状态
- **渲染 Agent 内容**: 流式输出展示、Markdown 渲染、文件预览等
- **AI 产物预览 (Artifact 渲染器)**: 位于 `src/renderer/services/artifact-renderer/`,sandboxed iframe 隔离渲染 AI 生成的 HTML / SVG / Mermaid / React 组件 / 代码块等产物,产物源来自 Go Agent 的 IPC payload,按类型分派后注入 iframe,不允许 `innerHTML` 直写主页面 DOM

## IPC 流向
```
Go Agent ──→ (stdout/pipe) ──→ 主进程 IPC ──→ preload ──→ Vue3 ──→ 渲染内容
     ↑                                   │
     └───────── 数据读写请求 ─────────────┘
```

### Queue Mode 矩阵

| 调用 | 入队 channel | 行为 | busy 时返回 |
|------|--------------|------|-------------|
| `Agent.Prompt(ctx, msg)` | `promptCh` (buffer 1) | 立即入队并触发 Run | `ErrAgentBusy` |
| `Agent.Steer(ctx, msg)` | `steerCh` (buffer 1) | 先 `cancelFn()` 取消当前 run，再入队；下一轮 messages 头部注入 | 总是入队成功（idle 等价 Prompt） |
| `Agent.FollowUp(ctx, msg)` | `followupCh` (buffer 16) | 入队；idle 时立即触发 Run，running 时等 `AgentEndEvent` 后自动触发 | 总是入队成功（buffer 满 → `ErrAgentBusy`） |
| `Agent.Abort(ctx)` | — | cancel 当前 `runCtx` | 总是成功（idle no-op）|

### 关键事件契约

| 事件 | 触发时机 | payload |
|------|----------|---------|
| `PromptReceivedEvent` | Run 的 dequeue 取到一条入队消息 | `Content, Mode` |
| `RunStartEvent` | Run 入口 | `SessionID` |
| `RunEndEvent` | 每条入队消息消费完成 | `Turns` |
| `TurnStartEvent` | 每个 turn 入口 | `TurnID, TurnIndex` |
| `LLMStartEvent` | provider.Stream 之前 | `Model` |
| `TextDeltaEvent` | 透传 provider 的每个 delta | `Delta` |
| `LLMEndEvent` | provider.DoneEvent 之后 | `Assistant Message, Usage` |
| `ToolStartEvent` | 每个 tool goroutine 启动 | `TurnID, CallID, Name, Arguments` |
| `ToolEndEvent` | 每个 tool goroutine 完成 | `CallID, Result, DurationMS` |
| `TurnEndEvent` | 每个 turn 出口 | `TurnIndex, StopReason` |
| `AgentEndEvent` | Run defer | `SessionID, TotalTurns, TotalUsage` |
| `AgentErrorEvent` | error 路径 | `Err`（含 `ErrAborted` / `ErrMaxTurns` / 其他） |

事件按以上顺序全链路可见；订阅方 buffer 满时按 **drop-oldest** 策略丢老事件（不阻塞 Agent）。

### 中止（Abort）路径

```
User Ctrl-C / Agent.Abort(ctx)
  └→ Agent.cancelFn()            ──→ runCtx 取消
       ├─→ provider.Stream 收到 ctx.Done()  ──→ 关闭 HTTP body；事件 channel 提前 close
       │     └─→ drainStream 退出循环 ──→ executor 收到 ctx.Canceled
       │           └─→ 写 assistant msg (stopReason=aborted) 到 session
       │                 └─→ emit(TurnEndEvent{StopReason: aborted})
       ├─→ 正在跑的 tool goroutine 收到 ctx.Done()  ──→ shell 子进程被 ExecCommandContext kill
       │                                                 └─→ executeOneTool 返回 Result{IsError: "aborted"}
       │                                                       └─→ emit(ToolEndEvent)
       └─→ dispatcher 收到 context.Canceled → emit(AgentErrorEvent{Err: ErrAborted})
                                              └─→ Run 返回 ErrAborted
                                                  └─→ 状态回到 idle，可重入
```

### Message 落地形态

`session.Session` 在一次完整对话中累积：

```
[1] user         "读 main.go 并总结"
[2] assistant    "" + tool_calls=[{name: read_file, args: {path: main.go}}]
[3] tool         "<main.go 全文>"
[4] assistant    "main.go 启动了一个 net/http server..."
```

每条消息是 `llm.Message{Role, Content, ToolCalls?, ToolCallID?}`；下一轮 LLM 调用把整段历史作为 `req.Messages` 一次性发出去。本里程碑不做压缩/截断（ContextEngine 留给后续 spec）。

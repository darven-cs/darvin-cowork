# 项目描述
这是一个工作桌面agent,适用于日常工作,包括创作,数据分析,ppt制作,视频制作,日常文件处理等问题,是个人的贴心助手,配置个人工作流使用

# 技术选型
electron作为桌面开发,golang作为agent runtime去跑(electron子进程),Vue3是前端页面编写,Tailwind CSS v4 是前端样式方案(@tailwindcss/vite 接入),AI 产物预览走自建 sandboxed iframe 渲染器 (Artifact 渲染器)

## 前端
- **目标栈**: Vue3 + Tailwind CSS v4 + Artifact 渲染器
  - **Vue3**: 视图层框架,函数组件 + `<script setup>` 风格
  - **Tailwind CSS v4**: 通过 `@tailwindcss/vite` 插件接入;`index.css` 顶部 `@import "tailwindcss";`;样式优先 utility class,跨组件复用的设计 token 走 `@theme` 块
  - **Artifact 渲染器**: 位于 `src/renderer/services/artifact-renderer/`,sandboxed iframe 隔离渲染 AI 生成的 HTML / SVG / Mermaid / React 组件 / 代码块等产物,对外只暴露受控 API (`mount` / `update` / `destroy`)
- **当前状态**: Vanilla TS + HTML (Hello World 占位),按上述目标栈迁移中

## 后端
golang + sqlite

## 主进程数据管理
- **SQLite 存储**: 用户设置、对话历史、上下文缓存
- **IPC 通信**: 与 Go Agent、子进程管理、数据读写

## 渲染进程职责
- **前端 UI**: Vue3 组件渲染,Tailwind CSS v4 utility class 样式
- **状态管理**: Pinia 运行时状态
- **渲染 Agent 内容**: 流式输出展示、Markdown 渲染、文件预览等
- **AI 产物预览 (Artifact 渲染器)**: 位于 `src/renderer/services/artifact-renderer/`,sandboxed iframe 隔离渲染 AI 生成的 HTML / SVG / Mermaid / React 组件 / 代码块等产物,产物源来自 Go Agent 的 IPC payload,按类型分派后注入 iframe,不允许 `innerHTML` 直写主页面 DOM

## IPC 流向
```
Go Agent ──→ (stdout/pipe) ──→ 主进程 IPC ──→ preload ──→ Vue3 ──→ 渲染内容
     ↑                                   │
     └───────── 数据读写请求 ─────────────┘
```

## 规划功能
agent循环,工具调用,记忆系统,skills系统,mcp系统,上下文管理(压缩),模型切换,视频生成

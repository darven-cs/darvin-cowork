# 项目开发计划

## M1：模型接口文档
- `m1-anthropic-api.md` — Anthropic Claude API 完整定义
- `m1-gemini-api.md` — Google Gemini API 完整定义
- `m1-openai-api.md` — OpenAI GPT API 完整定义
- `m1-model-provider.md` — 统一抽象接口设计

## M2：Agent 运行时开发
- `runtime.go` — 运行时核心（初始化、Step 循环）
- `agent.go` — Agent 定义（名称、指令、工具）
- `session.go` — 会话管理（上下文、历史、持久化）
- `executor.go` — 步骤执行器（模型调用、工具选择）
- `tool_registry.go` — 工具注册表

## M3：网关开发
- `server.go` — HTTP/WebSocket 主服务
- `router.go` — 路由定义
- `auth.go` — API Key 鉴权
- `ratelimit.go` — 限流器
- `proxy.go` — 上游代理
- `middleware.go` — 日志、追踪、CORS 中间件

## M4：基础页面开发

### 桌面组件框架
- `TitleBar/` — 自定义标题栏（窗口控制）
- `Sidebar/` — 侧边栏（Agent 列表、会话列表）
- `StatusBar/` — 状态栏

### 会话管理
- `ChatView.vue` — 聊天主视图
- `MessageBubble/` — 消息气泡组件
- `ChatInput/` — 输入组件
- `SessionList/` — 会话列表组件
- `stores/session.ts` — 会话状态管理
- `stores/chat.ts` — 聊天状态管理

## 开发顺序
M1 → M2 → M3 → M4（M1 是所有后续工作的基础）
